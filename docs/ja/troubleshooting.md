# 既知の制限、境界ケース、FAQ

[English](../troubleshooting.md) · [Русский](../ru/troubleshooting.md) · [简体中文](../zh/troubleshooting.md) · **日本語**

よくある質問への回答、サードパーティ ソフトウェアの癖、知っておくとよい Windows 11 自体の技術的な制約をまとめています。

---

## 1. 起動とシステムとの統合

### インストーラーを実行すると「Windows によって PC が保護されました」と表示される
ビルドにはまだコード署名がなく、SmartScreen は署名のない新しいファイルについて、十分なダウンロード数が集まるまで警告を出します。**詳細情報 → 実行** をクリックしてください。各リリースのファイルは、このリポジトリの GitHub Actions がタグのソースからビルドしています。

### なぜ Polynya を管理者として実行してはいけないのですか？
メインのアプリ（`polynya.exe`）は必ず通常ユーザーとして実行してください。Windows にはユーザー インターフェイス特権分離（**UIPI**）の仕組みがあります。昇格して実行したアイランドは通常レベルのプロセスとの正常な通信を失い（特に Everything のファイル検索と一部のユーザー イベントが動かなくなります）、ランチャーから開いたすべてのプログラムが管理者トークンを引き継いでしまいます。

### Windhawk（または他のタスクバー カスタマイズ ツール）を使っていて、アイランドの色がタスクバーと合いません
アイランドがタスクバーの質感と色を取り込み直すのは、システム イベント（テーマ、壁紙、アクセント カラーの変更、`explorer.exe` の再起動）のときだけです。タイマーで画面キャプチャを繰り返さないためです。Windhawk のような mod は、Windows の通知を送らずにメモリ上で直接タスクバーを塗り替えます。
* **対処：** トレイの Polynya アイコンを右クリックして **「外観を更新」** を選ぶか、ターミナルで `polynya refresh` を実行してください。

### タスクバーが縦置きや自動的に隠れる設定のとき、アイランドはどうなりますか？
* **タスクバーが下または上：** どちらも完全に対応しています。
* **縦置きのタスクバー（画面の横）：** 現在のバージョンではアイランドは自動的に隠れ、横置きのタスクバーを前提とするモジュールは起動しません。縦置きレイアウトへの対応は予定しています。
* **自動的に隠れるタスクバー：** スライドして隠れるタスクバーにアイランドを連動させる機能は、まだ実装されていません。
* **複数モニター：** アイランドはメイン タスクバーのあるモニターに置かれます。

### 拡大率の異なるディスプレイを接続した後、タスクバーの枠線が太くなった
拡大率の異なるディスプレイ（テレビ、プロジェクター、リモート画面）を接続して切断すると、エクスプローラーが再起動するまでタスクバーの枠線が太いまま残ることがあります。アイランドはタスクバーを取得するたびに枠線の太さを測り、ドロップダウンの下で続けて描くため、継ぎ目は出ません。太い枠線そのものは Windows の動作です。
* **解決方法：** エクスプローラーを再起動する（タスク マネージャー → エクスプローラー → 再起動）か、サインアウトして再度サインインしてください。アイランドは新しいタスクバーに自動で結び付きます。

### なぜ文字は ClearType ではなくグレースケールでアンチエイリアスされるのですか？
アイランドは透明な DirectComposition サーフェスに描画しています。Direct2D / Windows では、アルファ チャネルを持つ透明な背景の上で ClearType のサブピクセル アンチエイリアスを使うことは技術的に不可能です（グリフのラスタライズ時に色の分かった不透明な下地が必要なため）。そのためグレースケールのアンチエイリアスを使い、中国語と日本語ではさらにピクセル グリッドへのスナップ（`GDI_NATURAL`）を有効にしています。

## 2. 検索、天気、プレーヤー

### 検索でファイルやフォルダーが見つかりません（プログラムだけ）
重いディスク インデックスを自前で作らずに即時のファイル検索を行うため、Polynya はシステムにインストールされた **[Everything](https://www.voidtools.com/)** の IPC（`WM_COPYDATA`）を使っています。
* インストーラーで Polynya を入れる際に Everything のチェックを外した場合（またはポータブル版をダウンロードした場合）は、Everything がインストールされてバックグラウンドで動いていることを確認してください。Everything がないと、ランチャーはエクスプローラーの標準検索（「Windows で検索」）を提示します。

### 天気が表示されません
Windows の位置情報サービスがオフで、**かつ**アイランドの設定に都市を手入力していない場合、Open-Meteo に問い合わせる座標がわかりません（ログに `location unavailable and no city set` が記録されます）。
* **対処：** ランチャーで「設定」->「天気」を開き、「位置情報から取得」をオフにして都市名を入力してください。

### VPN を使っていると、Spotify の曲の更新が最大 30 秒遅れ、カバー画像も出ません
これは Windows 版 Spotify クライアント自体の挙動です。カバー画像の CDN（`i.scdn.co`）へのアクセスがブロックされていたり遅かったりすると、Spotify は内部のタイムアウト（約 30 秒）まで、更新された曲のメタデータを Windows のメディア セッション（GSMTC）に公開しません。Polynya は遅い回線向けにカバー画像を時間差で読み直します（0.4 / 1.2 / 2.5 秒後）が、CDN に届かない状態の Spotify 自体を速くすることはできません。

## 3. 通知とメッセンジャー

### 試験的な Windows 通知モジュールを有効にしたのに、Telegram Desktop のメッセージが表示されません
公式の **Telegram Desktop** クライアントは、既定では Windows の通知センターを使わず、独自の通知ウィンドウを描画します。
* **対処：** *Telegram の設定 -> 通知とサウンド* を開き、**「Windows の通知を使用」（Use Windows notifications）** にチェックを入れてください（AyuGram などの一部のフォーク版では最初から有効になっています）。

### システム通知のドロップダウンに相手のアバターや返信ボタンがなく、クリックすると特定のチャットではなくアプリ自体が開くのはなぜですか？
これは、Windows でサードパーティのプロセスが使える公開 API `UserNotificationListener` の制約です。
* システムがリスナーに渡すのは、トーストのテキスト フィールドとアプリの ID（`AUMID`）だけです。添付された画像やアバター、操作ボタン、アプリが特定の会話を開くために使う内部の起動引数（`launch arguments`）は渡されません。そのため、ドロップダウンをクリックすると `shell:AppsFolder\<AUMID>` を通じてアプリ自体を起動するか、前面に出します。

### まったく新しいプログラムからの最初の通知が、一度だけ標準の Windows バナーで表示されたのはなぜですか？
Windows がレジストリにそのアプリの `Notifications\Settings\<AUMID>` キーを作るのは、そのプログラムが最初の通知を表示したときです。最初の通知が届くと、`notify` モジュールはそのアプリを `banners-known.txt` に記録し、以降の起動では重複するバナーを前もってオフにします。

### 通知モジュールのインストール時に別の（管理者）アカウントで UAC を承認したら、モジュールが起動しません
システム パッケージ `Polynya.Notify` は、UAC のウィンドウで資格情報を入力した Windows ユーザーのプロファイルに登録されます。標準アカウントを使っていて、UAC で別のローカル管理者のパスワードを入力した場合、パッケージはその管理者のプロファイルにインストールされます。

### 「応答不可」（集中モード）のとき、重要なアラームや優先通話さえアイランドに表示されないのはなぜですか？
Windows で「応答不可」がオンのとき（`ToastNotificationManager.NotificationMode != Unrestricted`）や、プレゼンテーション中、全画面ゲームの間は、アイランドはドロップダウンのポップアップを完全に止めます。Windows 自身はこのモードでもユーザーが指定した優先アプリの通知を通せますが、その一覧は公開 API で提供されていないため、アイランドはすべてのアプリに対して沈黙します。
