# ユーザー ガイド

[English](../guide.md) · [Русский](../ru/guide.md) · [简体中文](../zh/guide.md) · **日本語**

このドキュメントでは、Polynya の日常的な使い方をまとめています。タスクバーでのレイアウトの仕組み、検索ランチャーでできること、プレーヤーと天気の設定、インストール・更新・削除の方法、ファイルの保存場所、そして `config.ini` とコマンドラインのキーについて説明します。

---

## 1. アイランドがタスクバーに住む仕組み

* **トレイとアイコンはクリック可能なまま。** ツールのウィンドウはメイン モニターのタスクバー全幅に広がっていますが、マウスを受け取るのは*何かが描画されている場所だけ*です（アイランドのブロック、通知チップ、開いているドロップダウン）。それ以外の領域はクリックを透過するため、システム トレイや実行中のプログラムのアイコンはいつもどおり動作します。
* **Windows アイコンの配置（`TaskbarAl`）。** Windows 11 のタスクバー アイコンが**中央揃え**の場合、アイランドは自動的にタスクバー左側の空き領域（スタート ボタンまで）に入り、右へ伸びます。アイコンが**左揃え**の場合、アイランドはタスクバーのちょうど中央に置かれます。
* **タスクバーが下または上。** どちらにも対応しています。タスクバーが下にあるときは、ドロップダウンは上向きに（鏡像の形で）伸びます。タスクバーが縦置き（画面の横）のときは、アイランドは非表示になります。
* **複数モニター。** アイランドはメイン タスクバーのあるモニターに置かれ、メイン ディスプレイや解像度を変えると自動的に追従します。
* **全画面モード。** モニターで全画面のゲーム、動画、プレゼンテーションが開かれると、アイランドは隠れ、フレームの描画と音声解析を完全に止めます。それでも `Alt+Space` での検索は全画面ウィンドウの上に表示されます。

### ブロックの配置
セグメントの並び順は、タスクバー上のシステム アイコンの位置によって変わります。

* **中央のアイランド**（Windows のアイコンが左揃えの場合）：
  1. **プレーヤーとビジュアライザー**（左へ伸びる）
  2. **時刻と天気**（プレートの上で、ちょうど中央に固定）
  3. **検索ボタン**（プレートの上の虫眼鏡、右へ伸びる）
  4. **右側の通知ゾーン**（チップと「+N」の束、右へ伸びる）
  ホバーするとセグメントは右へ広がり、中央の時刻ブロックは動きません。
* **左側のアイランド**（Windows のアイコンがタスクバー中央にある場合）：
  アイランドはスタート ボタンまでの左側の空き領域を使い、全体が左から右へ伸びます。
  1. **時刻と天気**（プレートの上）
  2. **検索ボタン**（プレートの上）
  3. **プレーヤーとビジュアライザー**
  4. **通知ゾーン**（チップと「+N」の束）

## 2. 時刻と天気

### 時計
* 現在の時刻と日付を表示します。分が変わると、変化した数字が滑らかにスクロールします。
* **ホバー：** 日の出と日の入りの時刻を表示します。
* **クリック：** Windows 標準の通知センターとカレンダーを開きます。

### 天気
* データは **Open-Meteo** から取得します（無料、API キー不要）。
* **都市の決定：** 既定では Windows の位置情報（`Geolocator`）と、**Nominatim**（OpenStreetMap）による逆ジオコーディングを使います。このモードでは都市名の横にナビゲーション アイコンが表示されます。設定で自動取得をオフにして、任意の都市を手入力することもできます（再起動なしですぐに反映）。
* **ホバー：** 「体感」温度、風速、湿度を表示します。
* **クリック：** 数時間先までの 1 時間ごとの予報と 3 日間の予報を表示するドロップダウンを開きます。

## 3. プレーヤーとビジュアライザー

* **対応プレーヤー：** Windows にメディア セッション（GSMTC）を公開するあらゆるアプリに対応します。Spotify、ブラウザー（YouTube、Yandex Music、SoundCloud など）、Telegram、デスクトップ プレーヤー。複数のプレーヤーが開いているときは、いま再生中のものが優先されます。
* **スクロール表示：** 長い曲名は、システムのコンポジター DWM によって滑らかにスクロールします（CPU 負荷はほぼありません）。
* **ホバーとクリック：** ホバーすると再生ボタン（前へ / 一時停止 / 次へ）、進行バー、時間表示が現れます。クリックすると、ぼかしたカバー画像を背景に大きなカバーを表示するドロップダウンが開き、バーをクリックしてシークできます。
* **分離されたビジュアライザー：** 5 バンドのスペクトラムは、WASAPI process loopback により*特定のプレーヤー プロセス*（ブラウザーの子プロセスを含む）の音声を聴きます。ゲームの音やメッセンジャーの通知音はイコライザーに影響しません。バンドが示すのは単純な音量ではなくダイナミクス（直近 1.5 秒の平均的な背景からどれだけ上回ったか）です。

## 4. 検索ランチャー（`Alt+Space` または虫眼鏡をクリック）

ランチャーは、ソフトウェアの起動、内蔵コマンドの呼び出し、ファイル検索、手早い計算を担います。プログラムのカタログは起動 10 秒後にバックグラウンドで事前に読み込まれるため、検索はすぐに開きます。

### 検索できるもの・できること
* **アプリとモジュールのコマンド。** すべてのデスクトップ アプリとストア アプリ（`shell:AppsFolder`）をあいまい入力で検索します（例：`vsc` で *Visual Studio Code* が見つかります）。内蔵コマンド（「設定」「カラーピッカー」とサードパーティ モジュールのコマンド）は、対応するすべての言語の名前とキーワードで同時に照合されます。
* **最近使ったもの。** クエリが空のときは、最近起動したプログラムとコマンドを混在させて表示します。入力中は、よく使う項目に少しだけスコアが加算されます（同点の場合、モジュールのコマンドは常に通常のプログラムより上になります）。
* **ファイル検索（Everything 経由）。** Everything がインストールされて動いていれば、数文字入力した時点で結果にファイルとフォルダーが現れます。Everything がない場合は、下に「Windows で検索」の行が表示されます。
* **電卓。** 入力しながら計算します。
  * 四則演算、かっこ、定数（`pi`）、平方根（`√16`）、度単位の三角関数（`sin(30)`）
  * 浮動小数点の許容誤差付きの比較（`0.1 + 0.2 == 0.3` -> `true`）
  * 文字列演算（`"ha" * 3` -> `hahaha`）
  * `Enter` で答えをクリップボードにコピーします。最後の計算はウィンドウを閉じてから 10 分間保持されるので、検索を開き直してすぐに `+ 15` と続けられます。
* **通貨換算。** 自然な言い回しと通貨コードを理解します：`100$`、`100 usd to eur`、`10 долларов в рубли`。換算先が指定されていない場合（`100$`）は、Windows の地域設定の通貨に換算します。為替レートは `open.er-api.com` から取得し、レートの日付は右側のヒントに表示されます。

### コンテキスト メニューと入力
* **右クリックのアクション メニュー：** 結果の行を右クリックすると、ドロップダウン内でサブメニューが滑らかに展開します：*開く*、*管理者として実行*、*エクスプローラーで表示*、*パスをコピー*、*最近使ったものから削除*、*アンインストール*（もう一度右クリックすると閉じます）。
* **本格的な入力欄：** マウスとキーボードでの選択、`Ctrl+A/C/X/V`、多段階の `Ctrl+Z` 取り消し、単語単位の移動と削除（`Ctrl+矢印`、`Ctrl+Backspace`）、そしてアジア言語の入力方式（**IME**）に対応し、検索を呼び出したウィンドウの入力状態を引き継ぎます。

## 5. モジュール

ランチャー、時刻と天気、プレーヤー、通知スタック以外の機能はモジュールが担います。モジュールは設定でオン・オフを切り替えます（6 章）。自作する方法は [モジュール API](module-api.md) にあります。

### AI エージェント（`agents` モジュール）
Claude Code、Codex、Cursor の状態を通知スタックに表示します。思考中、ファイルを編集中、入力待ち、完了のいずれかです。フックはモジュールをオンにしたときにエージェントの設定へ書き込まれ、オフにすると取り除かれます。詳しくは [通知、AI エージェント、ターミナル](notifications.md) を参照してください。

### カラーピッカー（`picker` モジュール）
ランチャーの **「カラーピッカー」** コマンドで呼び出します。
* 画面を止めずに動くスクリーン ルーペを開きます（アイランド自身からも色を取れます）。
* クリックすると色の HEX コードをクリップボードにコピーし、タスクバーにチップを表示します。
* カラーピッカーのチップをクリックすると、その色の **OKLCH 空間での 11 段階のシェード**のパレットが展開します（Tailwind のスケールと同じ考え方で、元の色はそのまま最も近い段階に置かれます）。どの色見本をクリックしても、その HEX がコピーされます。

### Windows 通知（`notify` モジュール、試験的）
既定では無効です。Windows のシステム通知を、標準のバナーの代わりにアイランドに表示します。オンにするときに一度だけ UAC が求められ、モジュールのパッケージを登録します。詳しい説明と制限は [通知、AI エージェント、ターミナル](notifications.md) を参照してください。

### 開発ツール（`devtools` モジュール）
> **開発中：** 現在のリリースにはまだ含まれていません。今後のリリースで追加されます。

Web 開発向けの小さなツールです。このモジュールは **Node.js** で動くので、Node.js がインストールされ `PATH` に入っている必要があります。
* **選択範囲の変換（`Ctrl+Alt+D`）。** 任意のアプリで値を選択（またはコピー）してホットキーを押すと、変換候補の一覧が出ます。Enter で選んだ候補がコピーされ、チップが表示され、フォーカスが元のアプリに戻るので、そのまま `Ctrl+V` で貼り付けられます。CSS の行の中の値はその場で変換されます。`padding: 16px 24px` は `padding: 1rem 1.5rem` になります。
  * サイズ：`px`、`rem`、`em`、`pt`。2 つのサイズ（`16px 24px`）からは可変の `clamp()` も作られます。
  * 色：HEX、RGB、HSL、OKLCH。
  * Unix 時刻（秒とミリ秒）と ISO 8601 の日付。
  * JSON（整形と圧縮）、JWT（ヘッダーとペイロード）、Base64、URL エンコード、名前の書式（`camelCase`、`snake_case`、`kebab-case` など）。
* **検索の *開発ツール* コマンド**でツールの一覧が開きます。変換、3 つの画面幅で確認できる可変サイズ、ID の生成（UUID、nanoid、hex）、現在時刻、ハッシュ（SHA-256、SHA-1、MD5）、ダミーテキストがあります。
* **設定**（同じ一覧にあります）：`rem` の基準となるルートのフォントサイズ、`clamp()` の画面幅の範囲、小数点以下の桁数。
* ホットキーは `config.ini` で変更または無効化できます：`hotkey.devtools.convert = Ctrl+Shift+Q`。

### 独自のスタート メニュー（`start` モジュール）
> **開発中：** 現在のリリースにはまだ含まれていません。今後のリリースで追加されます。

`Win` キーの単独押し、`Ctrl+Esc`、スタート ボタンの左クリックで、大きな標準メニューの代わりに開きます（横置きのタスクバーでのみ動作）。
* システムのショートカット（`Win+E`、`Win+D`、`Win+Shift+S`、`Win+L` など）、`Ctrl+Shift+Esc` のタスク マネージャー、スタート ボタンの右クリック メニュー（`Win+X`）は通常どおり動作します。
* 項目：*バージョン情報*、*設定*、*タスク マネージャー*、*スリープ*、*再起動*、*シャットダウン*、*ロック*、*サインアウト*。
* **誤操作の防止：** 再起動、シャットダウン、サインアウトは、3 秒以内のもう一度のクリックで確定します（システムのダイアログではなく、減っていくバー付きの確認が表示されます）。
* **「バージョン情報」画面：** カラーの ASCII による Polynya のマーク、Windows のバージョン、プロセッサのモデル、メモリ容量、グラフィックス カード、ディスクの空き容量、システムの稼働時間を表示します。

## 6. 設定、トレイ、外観の更新

設定は、検索の **「設定」** コマンド、またはシステム トレイの Polynya アイコンから開けます。
* **テーマと天気の都市**はすぐに反映されます。
* **表示言語、モジュールの有効化/無効化、通知バナーのモード**は **「適用」** ボタンで反映されます（アイランドが `--relaunch` フラグ付きで自動的に再起動します）。これらを変更したままうっかりウィンドウを閉じた場合は、未保存の変更を失わないための確認画面が表示されます。
* **外観を更新（`polynya refresh`）：** テーマ、壁紙、アクセント カラーの変更やエクスプローラーの再起動のとき、アイランドは自動的にタスクバーの色を取り込み直します。ただし、**Windhawk** のように Windows のシステム イベントを経由せずにタスクバーを塗り替えるツールを使っている場合は、トレイで **「外観を更新」** をクリックしてください（または `polynya refresh` を実行します）。

## 7. 設定ファイル（`config.ini`）

設定は `%APPDATA%\Polynya\config.ini`、ポータブル版では `polynya.exe` の隣の `data\config.ini` に保存されます（初回起動時にコメント付きで作成されます）。形式は `キー = 値` で、コメントは `#` で始まります。設定の下部にある **「config.ini を開く」** ボタンですぐに開けます。

| キー | 指定できる値 | 既定値 | 説明 |
| :--- | :--- | :--- | :--- |
| `taskbar_height` | DIP の数値（拡大率 100% でのピクセル）/ 空 | *システムから取得* | タスクバーの高さを手動で上書きします（通常は自動検出）。 |
| `city` | 都市名 / 空 | *位置情報から* | 天気予報の都市（空の場合は Windows の位置情報を使用）。 |
| `language` | `ru`、`en`、`zh`、`ja` / 空 | *Windows の言語* | インターフェイスと内蔵モジュールの言語。 |
| `terminal_notify` | 秒数（`0` で無効） | `10` | ターミナルの長時間コマンドを通知するしきい値。 |
| `modules_off` | スペース区切りの `id` | *空* | 無効にした通常モジュール（例：`agents picker`）。 |
| `modules_on` | スペース区切りの `id` | *空* | 有効にした試験的モジュール（例：`notify`）。 |
| `notify_banners` | `ours` / `system` | `ours` | `notify` モジュールが有効なときにポップアップ バナーを誰が描くか：`ours`（アイランドのドロップダウン）または `system`（Windows のバナーを残し、アイランドにはチップだけを表示）。 |
| `theme` | `os`、`dark`、`light` | `os` | 文字とアイコンの色だけを制御します（背景とプレートは常に実際のタスクバーの色に合わせます）。 |
| `font` | フォント ファミリー名 / 空 | `Inter`（内蔵） | インターフェイスのカスタム フォント（システムにインストールされている場合。なければ内蔵の Inter、それも読み込めなければ Segoe UI Variable Text または Segoe UI）。 |
| `hotkey.<モジュール>.<コマンド>` | `Ctrl+Alt+D` のようなホットキー / 空 | *モジュールの指定* | モジュールのコマンドのホットキーを上書きします。空にすると無効になります（例：`hotkey.translator.translate`）。 |
| `log` | `debug` / 空 | *通常* | 詳細なログを有効にします（曲名、カタログ走査の所要時間、タスクバー取り込みの詳細を含む）。 |

## 8. コマンドライン リファレンス（CLI）

すべてのコマンドはメインの `polynya` 実行ファイルで実行します。

```text
polynya
    タスクバーでアイランドを起動します。

polynya push <title> [details] [--key K] [--ttl SEC] [--icon ICON] [--meta TEXT]
    アイランドのスタックに通知（チップ）を送ります。
    オプション：
      --key K       通知のキー。同じキーで再度呼び出すと、既存のチップを更新します。
      --ttl SEC     表示時間（秒、既定は 10）。0 を指定すると閉じるまで表示し続けます。
      --icon ICON   チップのアイコン：ok | fail | info | key | claude | agent | color:#rrggbb
      --meta TEXT   展開したドロップダウンの下部に小さく表示する出典や時刻。
    （CLI からの詳細は 1 行目の 160 文字までに切り詰められます。）

polynya dismiss <K>
    キー K の通知をスタックから消します。

polynya refresh
    タスクバーの色、縁、ノイズを強制的に取り込み直します。

polynya notify-setup
    試験的な Windows 通知モジュール用のシステム パッケージをインストールし（UAC を求めます）、
    すぐにモジュールを起動します。

polynya modules reload
    モジュールのプロセスを再起動します（モジュールのコードを変更した後など）。

polynya modules enable|disable <id>...
    モジュールを有効または無効にします。アイランドの次回起動時に反映されます。

polynya language ru|en|zh|ja
    インターフェースの言語を設定します。アイランドの次回起動時に反映されます。

polynya quit
    アイランドを終了します。

polynya uninstall [--purge]
    アイランドを終了し、システムに登録した自動起動、AI エージェントのフック、通知パッケージを
    取り除きます。--purge を付けると設定とログも削除します。アンインストーラーが実行する
    コマンドで、プログラムのファイル自体は削除しません。

polynya help
    カラーの ASCII による Polynya のマーク、正確なビルド バージョン、コマンドの説明を表示します。
```

## 9. インストール、更新、削除

* **インストーラー。** 管理者権限なしで、現在のユーザー向けに `%LOCALAPPDATA%\Polynya` へインストールします。モジュールはチェックボックスで選びます。AI エージェントとカラーピッカーはオン、Windows 通知（試験的）はオフになっています。Everything がまだなければ、ファイル検索用に一緒にインストールでき、この手順だけ UAC が求められます。Windows へのサインイン時の自動起動もチェックボックスで選べます。
* **更新。** 新しいバージョンのインストーラーを実行すると、アイランドを終了し、ファイルを置き換えて再び起動します。設定、モジュールのオン・オフ、自動起動はそのまま残ります。インストール済みのモジュールは更新され、まだ入れていないモジュールは追加できます。
* **削除。** 設定 → アプリ → インストールされているアプリ → Polynya。アンインストーラーは自動起動、AI エージェントのフック、通知パッケージを取り除き、設定とログも削除するかを確認します。Everything は別のプログラムなので残ります。
* **ポータブル版。** `…-portable.zip` には `polynya.exe`、目印のファイル `portable`、ライセンスが入っています。好きな場所に展開すると、アイランドはそのフォルダーから動き、すべてを隣に保存します（`data\`、`logs\`、`modules\`）。モジュールは別の `…-modules.zip` に入っているので、同じフォルダーに展開してください。自動起動はトレイでオンにするまで無効です。AI エージェントのフックは、最後にフックを有効にしたアイランド（ポータブル版またはインストール版）を指します。
* **SmartScreen。** ビルドにはまだコード署名がないため、新しいバージョンの初回起動時に「Windows によって PC が保護されました」と表示されることがあります。**詳細情報 → 実行** をクリックしてください。

## 10. 保存場所（ファイル、ログ、レジストリ）

ポータブル版では、下の表の `%LOCALAPPDATA%\Polynya` と `%APPDATA%\Polynya` の代わりに `polynya.exe` のあるフォルダーが使われます。`modules\` と `logs\` はその隣に置かれ、`%APPDATA%\Polynya` のファイルは `data\` に入ります。

| パス / キー | 保存されている内容 |
| :--- | :--- |
| `%LOCALAPPDATA%\Polynya\polynya.exe` | コアの実行ファイル。 |
| `%LOCALAPPDATA%\Polynya\modules\<id>\` | モジュールのフォルダー（`module.toml` + モジュールの `.exe`）。 |
| `%LOCALAPPDATA%\Polynya\logs\polynya.log` | コアとモジュール共通のログ（1 MB で `polynya.old.log` にローテーションし、最大 2 ファイルを保持）。 |
| `%APPDATA%\Polynya\config.ini` | ユーザー設定。 |
| `%APPDATA%\Polynya\recent.txt` | ランチャーの起動履歴と頻度（`launches\ttime\tid`）。 |
| `%APPDATA%\Polynya\banners*.{txt,reg}` | `notify` モジュールによるシステム バナー設定のピンポイントなバックアップ。 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | サインイン時の自動起動エントリ。 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce\PolynyaBanners` | プロセスが異常終了した場合に `reg import` でシステム バナーを元に戻す保険。 |
