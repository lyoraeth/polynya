# 用户指南

[English](../guide.md) · [Русский](../ru/guide.md) · **简体中文** · [日本語](../ja/guide.md)

本文介绍 Polynya 的日常使用：任务栏中的布局如何工作、搜索启动器能做什么、播放器和天气如何设置、如何安装、更新和卸载、文件存放在哪里，以及 `config.ini` 和命令行中有哪些键。

---

## 1. “岛”如何驻留在任务栏中

* **托盘和图标仍可点击。** 工具的窗口横跨主显示器任务栏的整个宽度，但*只在有内容绘制的地方*接收鼠标（“岛”的区块、通知卡片、打开的下拉面板）。其余区域对点击是透明的，系统托盘和正在运行程序的图标照常工作。
* **Windows 图标对齐方式（`TaskbarAl`）。** 如果 Windows 11 任务栏图标**居中**，“岛”会自动占据任务栏左侧的空闲区域（直到“开始”按钮）并向右扩展。如果图标**靠左对齐**，“岛”会位于任务栏正中央。
* **任务栏在底部或顶部。** 两种都支持。任务栏在底部时，下拉面板会向上生长（形状镜像）。任务栏垂直放置（在屏幕侧边）时，“岛”会隐藏。
* **多显示器。** “岛”位于主任务栏所在的显示器上，更换主显示器或分辨率时会自动跟随。
* **全屏模式。** 当显示器上打开全屏游戏、视频或演示时，“岛”会隐藏，并完全停止绘制帧和分析音频。此时用 `Alt+Space` 调出搜索，仍然会显示在全屏窗口之上。

### 区块布局
各个区块的顺序取决于系统图标在任务栏中的位置：

* **居中的“岛”**（Windows 图标靠左对齐时）：
  1. **播放器与可视化**（向左扩展）；
  2. **时间与天气**（位于正中央，带底板）；
  3. **搜索按钮**（带底板的放大镜，向右扩展）；
  4. **右侧通知区**（卡片和 “+N” 堆叠，向右扩展）。
  悬停时区块向右展开，不会移动中央的时间区块。
* **靠左的“岛”**（Windows 图标居中时）：
  “岛”占据直到“开始”按钮的左侧空闲区域，整体从左向右扩展：
  1. **时间与天气**（带底板）；
  2. **搜索按钮**（带底板）；
  3. **播放器与可视化**；
  4. **通知区**（卡片和 “+N” 堆叠）。

## 2. 时间与天气

### 时钟
* 显示当前时间和日期；分钟变化时，变化的数字会平滑滚动。
* **悬停：** 显示日出和日落时间。
* **点击：** 打开 Windows 标准的通知中心和日历。

### 天气
* 数据来自 **Open-Meteo**（免费，无需 API 密钥）。
* **城市确定：** 默认使用 Windows 定位（`Geolocator`），并通过 **Nominatim**（OpenStreetMap）反向地理编码；此模式下城市名旁会显示导航图标。也可以在设置中关闭自动定位，手动输入任意城市（立即生效，无需重启）。
* **悬停：** 显示“体感”温度、风速和湿度。
* **点击：** 打开下拉面板，显示未来几小时的逐小时预报和未来 3 天的预报。

## 3. 播放器与可视化

* **支持的播放器：** 任何在 Windows 中发布媒体会话（GSMTC）的应用：Spotify、浏览器（YouTube、Yandex Music、SoundCloud 等）、Telegram、传统播放器。如果同时打开多个播放器，优先显示正在播放的那个。
* **滚动字幕：** 过长的曲名由系统合成器 DWM 平滑滚动（几乎不占用 CPU）。
* **悬停与点击：** 悬停时出现播放控制按钮（上一首 / 暂停 / 下一首）、进度条和时间。点击会打开一个下拉面板，以模糊后的封面为背景显示大封面，点击进度条即可跳转。
* **隔离的可视化：** 5 段频谱通过 WASAPI process loopback 监听*特定播放器进程*（包括浏览器的子进程）的音频。游戏声音或聊天软件的提示音不会影响均衡器。频段显示的不是原始音量，而是动态（相对过去 1.5 秒平均背景的超出量）。

## 4. 搜索启动器（`Alt+Space` 或点击放大镜）

启动器负责启动软件、调用内置命令、搜索文件和快速计算。程序目录会在启动 10 秒后于后台预热，因此搜索可以瞬间打开。

### 可以搜索和执行什么
* **应用与模块命令。** 搜索所有传统程序和应用商店程序（`shell:AppsFolder`），支持模糊输入（例如 `vsc` 可以找到 *Visual Studio Code*）。内置命令（“设置”、“取色器”以及第三方模块的命令）会同时按所有支持语言的名称和关键词匹配。
* **最近使用。** 查询为空时，显示最近启动的程序和命令（混合排列）。输入时，常用项会获得少量权重加成（得分相同时，模块命令总是排在普通程序之前）。
* **文件搜索（通过 Everything）。** 如果系统中安装并运行了 Everything，输入几个字符后结果中就会出现文件和文件夹。没有 Everything 时，底部会提供“在 Windows 中搜索”一行。
* **计算器。** 边输入边计算：
  * 算术、括号、常量（`pi`）、根号（`√16`）、以角度为单位的三角函数（`sin(30)`）；
  * 带浮点容差的比较（`0.1 + 0.2 == 0.3` -> `true`）；
  * 字符串运算（`"ha" * 3` -> `hahaha`）。
  * 按 `Enter` 把结果复制到剪贴板。窗口关闭后最后一次计算会保留 10 分钟，可以重新打开搜索直接接着输入 `+ 15`。
* **货币换算。** 理解自然语言查询和货币代码：`100$`、`100 usd to eur`、`10 долларов в рубли`。如果没有指定目标货币（`100$`），会换算为你 Windows 区域的本币。汇率来自 `open.er-api.com`，汇率日期显示在右侧提示中。

### 右键菜单与输入
* **右键操作菜单：** 在结果行上右键，会在下拉面板内平滑展开子菜单：*打开*、*以管理员身份运行*、*在资源管理器中显示*、*复制路径*、*从最近使用中删除*、*卸载*（再次右键收起）。
* **完整的输入框：** 支持鼠标和键盘选择、`Ctrl+A/C/X/V`、多级 `Ctrl+Z` 撤销、按词跳转和删除（`Ctrl+方向键`、`Ctrl+Backspace`），以及亚洲语言输入法（**IME**），并沿用你调出搜索时所在窗口的输入状态。

## 5. 模块

启动器、时间与天气、播放器和通知堆栈之外的功能都由模块提供。模块在设置中启用和禁用（见第 6 节）；如何编写自己的模块，请参阅 [模块 API](module-api.md)。

### AI 代理（`agents` 模块）
在通知堆栈中显示 Claude Code、Codex 和 Cursor 的状态：代理正在思考、编辑文件、等待输入或已完成。启用模块时会把钩子写入代理的配置，禁用时移除。详见 [通知、AI 代理与终端](notifications.md)。

### 取色器（`picker` 模块）
在启动器中通过 **“取色器”** 命令调用。
* 打开一个实时的屏幕放大镜，不会冻结屏幕画面（甚至可以从“岛”本身取色）。
* 点击后把颜色的 HEX 代码复制到剪贴板，并在任务栏中显示一个卡片。
* 点击取色器的卡片，会展开该颜色在 **OKLCH 空间中的 11 级色阶**（类似 Tailwind 色阶，原始颜色不变地落在最近的一级上）。点击任意色块即可复制其 HEX。

### Windows 通知（`notify` 模块，实验性）
默认关闭。在“岛”中显示 Windows 系统通知，代替标准横幅。启用时会请求一次 UAC，用于注册模块的软件包。详细说明与限制见 [通知、AI 代理与终端](notifications.md)。

### 开发工具（`devtools` 模块）
> **开发中：** 当前版本尚未提供，将在后续版本中加入。

面向 Web 开发的小工具。该模块运行在 **Node.js** 上，需要已安装并加入 `PATH`。
* **转换所选内容（`Ctrl+Alt+D`）。** 在任意程序中选中一个值（或复制它），然后按下快捷键。会出现一个转换结果列表；按 Enter 复制所选结果，显示一张卡片，并把焦点还给原程序，`Ctrl+V` 即可原地粘贴。CSS 行中的值会就地转换：`padding: 16px 24px` 变为 `padding: 1rem 1.5rem`。
  * 尺寸：`px`、`rem`、`em`、`pt`；两个尺寸（`16px 24px`）还会生成流式 `clamp()`。
  * 颜色：HEX、RGB、HSL、OKLCH。
  * Unix 时间（秒和毫秒）与 ISO 8601 日期。
  * JSON（格式化与压缩）、JWT（头部与载荷）、Base64、URL 编码、命名风格（`camelCase`、`snake_case`、`kebab-case` 等）。
* **搜索中的 *开发工具* 命令**会打开工具列表：转换器、可在三种屏幕宽度下预览的流式尺寸、ID 生成（UUID、nanoid、hex）、当前时间、哈希（SHA-256、SHA-1、MD5）和占位文本。
* **设置**（在同一列表中）：用于 `rem` 的根字号、用于 `clamp()` 的屏幕宽度范围，以及小数位数。
* 快捷键可以在 `config.ini` 中修改或关闭：`hotkey.devtools.convert = Ctrl+Shift+Q`。

### 自定义“开始”菜单（`start` 模块）
> **开发中：** 当前版本尚未提供，将在后续版本中加入。

在单独按下 `Win`、`Ctrl+Esc` 或左键点击“开始”按钮时，替代笨重的标准菜单（仅适用于水平任务栏）。
* 所有系统快捷键（`Win+E`、`Win+D`、`Win+Shift+S`、`Win+L` 等）、`Ctrl+Shift+Esc` 打开任务管理器，以及右键“开始”按钮的高级菜单（`Win+X`）都照常工作。
* 菜单内容：*关于*、*设置*、*任务管理器*、*睡眠*、*重启*、*关机*、*锁定*、*注销*。
* **防误触：** 重启、关机和注销需要在 3 秒内再次点击确认（会出现一个带递减进度条的问题，没有系统弹窗）。
* **“关于”页面：** 显示彩色 ASCII 版的 Polynya 标志、Windows 版本、处理器型号、内存容量、显卡、磁盘剩余空间和系统运行时间。

## 6. 设置、托盘与刷新外观

可以在搜索中使用 **“设置”** 命令，或通过系统托盘中的 Polynya 图标打开设置。
* **主题和天气城市**立即生效。
* **界面语言、启用/禁用模块以及通知横幅模式**通过 **“应用”** 按钮生效（“岛”会带着 `--relaunch` 参数平稳地自行重启）。如果你修改了这些选项却不小心关闭了窗口，会出现一个防止丢失未保存更改的页面。
* **刷新外观（`polynya refresh`）：** 当主题、壁纸、强调色变化或资源管理器重启时，“岛”会自动重新采集任务栏颜色。但如果你使用 **Windhawk** 等绕过 Windows 系统事件为任务栏重新着色的第三方工具，请在托盘菜单中点击 **“刷新外观”**（或运行 `polynya refresh`）。

## 7. 配置文件（`config.ini`）

设置保存在 `%APPDATA%\Polynya\config.ini` 中，便携版保存在 `polynya.exe` 旁边的 `data\config.ini` 中（首次启动时创建，附带注释）。格式：`键 = 值`，注释以 `#` 开头。可以通过设置底部的 **“打开 config.ini”** 按钮快速打开该文件。

| 键 | 可选值 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `taskbar_height` | DIP 数值（100% 缩放下的像素）/ 空 | *取自系统* | 手动覆盖任务栏高度（通常自动检测）。 |
| `city` | 城市名 / 空 | *按定位* | 天气预报的城市（为空时使用 Windows 定位）。 |
| `language` | `ru`、`en`、`zh`、`ja` / 空 | *Windows 语言* | 界面和内置模块的语言。 |
| `terminal_notify` | 秒（`0` 为关闭） | `10` | 终端长时间命令通知的时间阈值。 |
| `modules_off` | 以空格分隔的 `id` | *空* | 已禁用的普通模块（例如 `agents picker`）。 |
| `modules_on` | 以空格分隔的 `id` | *空* | 已启用的实验性模块（例如 `notify`）。 |
| `notify_banners` | `ours` / `system` | `ours` | 启用 `notify` 模块时由谁绘制弹出横幅：`ours`（“岛”的下拉面板）或 `system`（保留 Windows 横幅，“岛”中只显示卡片）。 |
| `theme` | `os`、`dark`、`light` | `os` | 只控制文字和图标的颜色（背景和底板始终适应任务栏的实际颜色）。 |
| `font` | 字体族名称 / 空 | `Inter`（内置） | 自定义界面字体（需已安装在系统中；否则使用内置的 Inter，若它也无法加载，则使用 Segoe UI Variable Text 或 Segoe UI）。 |
| `hotkey.<模块>.<命令>` | 形如 `Ctrl+Alt+D` 的快捷键 / 空 | *来自模块* | 改写模块命令的快捷键；为空则关闭（例如 `hotkey.translator.translate`）。 |
| `log` | `debug` / 空 | *普通* | 启用详细日志（包括曲名、目录遍历耗时和任务栏采集细节）。 |

## 8. 命令行参考（CLI）

所有命令都通过主程序 `polynya` 执行：

```text
polynya
    在任务栏中启动“岛”。

polynya push <title> [details] [--key K] [--ttl SEC] [--icon ICON] [--meta TEXT]
    向“岛”的堆栈发送一条通知（卡片）。
    参数：
      --key K       通知的 key。使用相同 key 再次调用会更新已有卡片。
      --ttl SEC     存活时间，单位秒（默认 10）。0 表示一直保留，直到被关闭。
      --icon ICON   卡片图标：ok | fail | info | key | claude | agent | color:#rrggbb
      --meta TEXT   展开的下拉面板底部的小字（来源/时间）。
    （CLI 中的详细内容会被截断为第一行和 160 个字符。）

polynya dismiss <K>
    从堆栈中移除 key 为 K 的通知。

polynya refresh
    强制重新采集任务栏的颜色、边缘和噪点。

polynya notify-setup
    为实验性的 Windows 通知模块安装系统软件包（会请求 UAC），并立即启动该模块。

polynya modules reload
    重启模块进程，例如在修改模块代码之后。

polynya modules enable|disable <id>...
    启用或禁用模块；在“岛”下次启动时生效。

polynya language ru|en|zh|ja
    设置界面语言；在“岛”下次启动时生效。

polynya quit
    关闭“岛”。

polynya uninstall [--purge]
    关闭“岛”，并撤销它在系统中注册的内容：自启动、AI 代理钩子和通知包。
    加上 --purge 还会删除设置和日志。卸载程序会调用此命令，程序文件本身不会被删除。

polynya help
    输出彩色 ASCII 版 Polynya 标志、精确的构建版本和命令说明。
```

## 9. 安装、更新和卸载

* **安装程序。** 为当前用户安装到 `%LOCALAPPDATA%\Polynya`，不需要管理员权限。用复选框选择模块：默认勾选 AI 代理和取色器，Windows 通知（实验性）不勾选。如果还没有安装 Everything，安装程序可以一并安装它用于文件搜索，这一步会请求 UAC。登录 Windows 时自动启动同样是一个复选框。
* **更新。** 运行新版本的安装程序：它会关闭“岛”、替换文件并重新启动。设置、模块开关和自启动保持不变。已安装的模块会被更新，之前没有安装的模块可以添加。
* **卸载。** 设置 → 应用 → 已安装的应用 → Polynya。卸载程序会移除自启动、AI 代理钩子和通知包，并询问是否一并删除设置和日志。Everything 会保留，它是独立的程序。
* **便携版。** `…-portable.zip` 中有 `polynya.exe`、标记文件 `portable` 和许可证。解压到任意位置：“岛”直接从该文件夹运行，所有内容都保存在旁边（`data\`、`logs\`、`modules\`）。模块单独放在 `…-modules.zip` 中，需要解压到同一文件夹。在托盘中开启之前，自启动是关闭的。AI 代理钩子指向最后一次启用它们的“岛”，可能是便携版，也可能是安装版。
* **SmartScreen。** 目前构建尚未签名，首次运行新版本时 Windows 可能显示“Windows 已保护你的电脑”：点击 **更多信息 → 仍要运行**。

## 10. 文件位置（文件、日志和注册表）

便携版中，下表的 `%LOCALAPPDATA%\Polynya` 和 `%APPDATA%\Polynya` 由 `polynya.exe` 所在的文件夹代替：`modules\` 和 `logs\` 位于它旁边，`%APPDATA%\Polynya` 中的文件放在 `data\` 中。

| 路径 / 注册表项 | 存放内容 |
| :--- | :--- |
| `%LOCALAPPDATA%\Polynya\polynya.exe` | 核心可执行文件。 |
| `%LOCALAPPDATA%\Polynya\modules\<id>\` | 模块文件夹（`module.toml` + 模块的 `.exe`）。 |
| `%LOCALAPPDATA%\Polynya\logs\polynya.log` | 核心与模块共用的日志（达到 1 MB 时轮转为 `polynya.old.log`，最多保留两个文件）。 |
| `%APPDATA%\Polynya\config.ini` | 用户设置。 |
| `%APPDATA%\Polynya\recent.txt` | 启动器的启动历史和频率（`launches\ttime\tid`）。 |
| `%APPDATA%\Polynya\banners*.{txt,reg}` | `notify` 模块对系统横幅设置的定点备份。 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` | 登录时自动启动的项。 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce\PolynyaBanners` | 进程异常终止时，通过 `reg import` 恢复系统横幅的保险措施。 |
