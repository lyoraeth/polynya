# 已知限制、边界情况与常见问题

[English](../troubleshooting.md) · [Русский](../ru/troubleshooting.md) · **简体中文** · [日本語](../ja/troubleshooting.md)

这里汇总了常见问题的解答、第三方软件的特殊行为，以及值得了解的 Windows 11 自身技术限制。

---

## 1. 启动与系统集成

### 运行安装程序时 Windows 提示“Windows 已保护你的电脑”
目前构建尚未签名，而 SmartScreen 会对任何新的未签名文件发出警告，直到它积累足够的下载量。点击 **更多信息 → 仍要运行** 即可。每个版本的文件都由本仓库的 GitHub Actions 根据标签对应的源码构建。

### 为什么不能以管理员身份运行 Polynya？
主程序（`polynya.exe`）必须以普通用户身份运行。Windows 有用户界面特权隔离机制（**UIPI**）：以提升权限运行的“岛”会失去与普通级别进程的正常通信（尤其是 Everything 文件搜索和部分用户事件将无法工作），而且你通过启动器打开的所有程序都会继承管理员令牌。

### 我在用 Windhawk（或其他任务栏美化工具），“岛”的颜色和任务栏对不上
“岛”只在系统事件（主题、壁纸或强调色变化，`explorer.exe` 重启）发生时重新采集任务栏的纹理和颜色，从而不必用定时器反复截屏。Windhawk 之类的模组直接在内存中为任务栏重新着色，不会发送 Windows 通知。
* **解决方法：** 右键单击托盘中的 Polynya 图标并选择 **“刷新外观”**，或在终端中运行 `polynya refresh`。

### 任务栏垂直放置或自动隐藏时，“岛”会怎样？
* **任务栏在底部或顶部：** 两种都完全支持。
* **垂直任务栏（在屏幕侧边）：** 当前版本中“岛”会自动隐藏，依赖水平任务栏的模块不会启动。垂直布局的支持已在计划中。
* **自动隐藏的任务栏：** 尚未实现“岛”与滑出的任务栏同步隐藏。
* **多显示器：** “岛”位于主任务栏所在的显示器上。

### 连接过不同缩放比例的显示器后，任务栏边框变粗了
连接并断开不同缩放比例的显示器（电视、投影仪、远程屏幕）后，资源管理器可能会保留较粗的任务栏边框，直到它重新启动。“岛”在每次截取任务栏时都会测量边框粗细，并在下拉面板下延续它，因此不会出现接缝；变粗的边框本身是 Windows 的行为。
* **解决方法：** 重新启动资源管理器（任务管理器 → Windows 资源管理器 → 重新启动），或注销后重新登录。“岛”会自动绑定到新的任务栏。

### 为什么文字使用灰度抗锯齿而不是 ClearType？
“岛”通过透明的 DirectComposition 表面渲染。在 Direct2D / Windows 中，带 Alpha 通道的透明背景在技术上无法使用 ClearType 子像素抗锯齿（字形光栅化时需要已知颜色的不透明底色），因此使用灰度抗锯齿，并且对中文和日文额外启用像素网格对齐（`GDI_NATURAL`）。

## 2. 搜索、天气与播放器

### 搜索找不到文件和文件夹（只有程序）
为了在不自行建立沉重磁盘索引的情况下实现即时文件搜索，Polynya 使用系统中已安装的 **[Everything](https://www.voidtools.com/)** 的 IPC（`WM_COPYDATA`）。
* 如果你用安装程序安装 Polynya 时取消勾选了 Everything（或下载的是便携版），请确认 Everything 已安装并在后台运行。没有它时，启动器会提供资源管理器的标准搜索（“在 Windows 中搜索”）。

### 天气不显示
如果系统关闭了 Windows 定位服务，**并且**没有在“岛”的设置中手动输入城市，工具就不知道该用哪个坐标查询 Open-Meteo（日志中会出现 `location unavailable and no city set`）。
* **解决方法：** 在启动器中打开“设置” -> “天气”，关闭“根据位置确定”开关，然后输入你的城市。

### 开启 VPN 时，Spotify 在播放器中更新曲目最多延迟 30 秒且没有封面
这是 Windows 上 Spotify 客户端本身的行为：如果它访问封面 CDN（`i.scdn.co`）被阻止或很慢，Spotify 会等到内部超时（约 30 秒）才把更新后的曲目元数据发布到 Windows 媒体会话（GSMTC）。Polynya 为慢速网络准备了延迟重读封面（0.4 / 1.2 / 2.5 秒后），但在 CDN 无法访问时无法让 Spotify 本身变快。

## 3. 通知与聊天软件

### 我启用了实验性的 Windows 通知模块，但 Telegram Desktop 的消息没有出现
官方 **Telegram Desktop** 客户端默认绘制自己的通知窗口，绕过了 Windows 通知中心。
* **解决方法：** 打开 *Telegram 设置 -> 通知和声音*，勾选 **“使用 Windows 通知”（Use Windows notifications）**（AyuGram 等部分分支客户端默认已开启）。

### 为什么系统通知的下拉面板里没有对方头像和回复按钮，而且点击打开的是应用本身而不是具体聊天？
这些是 Windows 中公开的 `UserNotificationListener` API 对第三方进程的限制：
* 系统只向监听者提供通知的文本字段和应用标识（`AUMID`），不提供附带的图片/头像、交互式操作按钮，也不提供应用用来跳转到具体对话的内部启动参数（`launch arguments`）。因此点击下拉面板只会通过 `shell:AppsFolder\<AUMID>` 启动应用或把它调到前台。

### 为什么一个全新程序的第一条通知会以标准 Windows 横幅弹出一次？
Windows 只在某个程序显示第一条通知时，才会在注册表中创建该应用的 `Notifications\Settings\<AUMID>` 项。第一条通知到达后，`notify` 模块会把该应用记录到 `banners-known.txt`，之后每次启动都会提前关闭其重复横幅。

### 安装通知模块时，我在 UAC 中使用了另一个（管理员）账户确认，结果模块无法启动
系统软件包 `Polynya.Notify` 会注册到在 UAC 窗口中输入凭据的那个 Windows 用户的配置文件中。如果你使用的是标准账户，却在 UAC 中输入了另一个本地管理员的密码，软件包就会安装到那位管理员的配置文件中。

### 为什么在“请勿打扰”（专注助手）模式下，“岛”连重要的闹钟和优先来电都不显示？
当 Windows 开启“请勿打扰”（`ToastNotificationManager.NotificationMode != Unrestricted`），以及在演示或全屏游戏期间，“岛”会完全停止弹出下拉面板。Windows 本身在此模式下可以放行用户优先应用列表中的通知，但这个列表没有通过公开 API 提供，所以“岛”对所有应用都保持安静。
