# Известные ограничения, граничные случаи и FAQ

[English](../troubleshooting.md) · **Русский** · [简体中文](../zh/troubleshooting.md) · [日本語](../ja/troubleshooting.md)

Здесь собраны ответы на частые вопросы, особенности стороннего софта и технические ограничения самой Windows 11, о которых стоит знать.

---

## 1. Запуск и интеграция с системой

### При запуске установщика Windows пишет "Система Windows защитила ваш компьютер"
Сборки пока не подписаны, а SmartScreen предупреждает о любом новом неподписанном файле, пока тот не наберет достаточно скачиваний. Нажмите **Подробнее → Выполнить в любом случае**. Файлы каждого релиза собирает GitHub Actions в этом репозитории из исходников по тегу.

### Почему нельзя запускать Polynya от имени администратора?
Запускать основное приложение (`polynya.exe`) нужно строго от обычного пользователя. В Windows действует механизм изоляции привилегий пользовательского интерфейса (**UIPI**): если запустить остров с повышенными правами, он потеряет нормальную связь с процессами обычного уровня (в частности, отвалится взаимодействие с поиском файлов Everything и перехват части пользовательских событий), а все программы, которые вы откроете через лаунчер, будут наследовать админский токен.

### Я использую Windhawk (или другой твикер панели задач), и цвета острова не совпали с панелью
Остров переснимает текстуру и цвет панели задач строго по системным событиям (смена темы, обоев, акцента, перезапуск `explorer.exe`), чтобы не гонять захват экрана по таймеру. Моды вроде Windhawk перекрашивают панель задач напрямую в памяти без отправки уведомлений Windows.
* **Решение:** кликните правой кнопкой по иконке Polynya в трее и нажмите **"Обновить вид"** или выполните в терминале `polynya refresh`.

### Как ведет себя остров при вертикальной или автоскрываемой панели задач?
* **Панель снизу или сверху:** полностью поддерживаются оба варианта.
* **Вертикальная панель (сбоку экрана):** в текущей версии остров автоматически прячется, а модули, привязанные к горизонтальной панели, не запускаются. Поддержка вертикальной раскладки - в планах.
* **Автоскрываемая панель задач:** синхронное скрытие острова вместе с уезжающей панелью пока не реализовано.
* **Несколько мониторов:** остров живет на мониторе основной панели задач.

### После подключения экрана с другим масштабом обводка панели задач стала толще
После подключения и отключения экрана с другим масштабом (телевизор, проектор, удалённый экран) проводник может оставить панели задач более толстую обводку — до своего перезапуска. Остров измеряет толщину обводки при каждом снимке панели и продолжает её под выпадашками, поэтому шва нет; сама толстая обводка — поведение Windows.
* **Решение:** перезапустите проводник (Диспетчер задач → Проводник → Перезапустить) или выйдите из системы и войдите снова. Остров сам привяжется к новой панели.

### Почему шрифты рисуются со сглаживанием оттенками серого, а не ClearType?
Окно острова рендерится через прозрачную композитную поверхность DirectComposition. В архитектуре Direct2D / Windows субпиксельное сглаживание ClearType технически невозможно на прозрачном фоне с альфа-каналом (для него требуется непрозрачная подложка известного цвета в момент растеризации глифа), поэтому используется grayscale-антиалиасинг, а для китайского и японского языков дополнительно включается привязка к пиксельной сетке (`GDI_NATURAL`).

## 2. Поиск, погода и плеер

### В поиске не ищутся файлы и папки (только программы)
Для мгновенного поиска файлов без собственной тяжелой индексации диска Polynya использует IPC установленного в системе **[Everything](https://www.voidtools.com/)** (`WM_COPYDATA`).
* Если вы ставили Polynya из установщика и сняли галочку с Everything (или скачали портативную версию), убедитесь, что Everything установлен и запущен в фоне. Без него лаунчер предложит стандартный поиск через проводник ("Искать в Windows").

### Погода не показывается
Если в системе выключена служба геолокации Windows **и** в настройках острова вручную не вписан город, утилита не знает координаты для запроса к Open-Meteo (в логе появится запись `location unavailable and no city set`).
* **Решение:** откройте "Настройки" в лаунчере -> раздел "Погода", выключите переключатель "Определять по местоположению" и введите свой город текстом.

### В Spotify с включенным VPN трек в плеере обновляется с задержкой до 30 секунд и без обложки
Это особенность работы самого клиента Spotify на Windows: если у него заблокирован или тормозит доступ к CDN обложек (`i.scdn.co`), приложение Spotify не публикует обновленные метаданные трека в системную медиасессию Windows (GSMTC), пока не отвалится по внутреннему таймауту (~30 секунд). Со стороны Polynya предусмотрены повторные чтения обложек с задержкой (через 0,4 / 1,2 / 2,5 с) для медленного интернета, но ускорить сам Spotify при недоступном CDN нельзя.

## 3. Уведомления и мессенджеры

### Включил экспериментальный модуль уведомлений Windows, но сообщения из Telegram Desktop не появляются
Официальный клиент **Telegram Desktop** по умолчанию рисует собственные кастомные окошки уведомлений в обход системного центра Windows.
* **Решение:** откройте *Настройки Telegram -> Уведомления и звук* и включите галочку **"Уведомления Windows" (Use Windows notifications)** (в некоторых клиентах-форках вроде AyuGram она уже работает из коробки).

### Почему в выпадашке системного уведомления нет аватарки собеседника, кнопок ответа, а клик открывает само приложение, а не конкретный чат?
Это ограничения публичного API `UserNotificationListener` для сторонних процессов в Windows:
* Система отдает слушателю только текстовые поля тоста и идентификатор приложения (`AUMID`), но не отдает прикрепленные картинки/аватары, интерактивные кнопки действий и внутренние аргументы запуска (`launch arguments`), по которым приложение переходит в конкретный диалог. Поэтому клик по выпадашке запускает или выводит на передний план само приложение через `shell:AppsFolder\<AUMID>`.

### Почему первое уведомление от совершенно новой программы один раз всплыло стандартным баннером Windows?
Windows создает ветку приложения в реестре `Notifications\Settings\<AUMID>` только в момент показа самого первого уведомления от этой программы. Как только первое уведомление пришло, модуль `notify` запоминает приложение в `banners-known.txt` и при всех следующих запусках отключает его дублирующий баннер заранее.

### При установке модуля уведомлений подтвердил UAC под другой (админской) учетной записью - модуль не запускается
Системный пакет `Polynya.Notify` регистрируется в профиле того пользователя Windows, чьи данные были введены в окне UAC. Если вы сидите под ограниченной учетной записью, а в UAC ввели пароль другого локального администратора, пакет встанет в профиль этого администратора.

### Почему в режиме "Не беспокоить" (Focus Assist) остров не показывает даже важные будильники и приоритетные вызовы?
Когда в Windows включен режим "Не беспокоить" (`ToastNotificationManager.NotificationMode != Unrestricted`), а также во время презентаций или полноэкранных игр, остров полностью прекращает всплывать выпадашками. Сама Windows в этом режиме умеет пропускать уведомления из пользовательского списка приоритетных приложений, но этот список не публикуется через открытый API, поэтому остров молчит для всех.
