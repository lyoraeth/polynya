## Как сообщить об уязвимости

Пожалуйста, **не публикуйте сообщения об уязвимостях в публичных GitHub Issues**.

Если вы нашли проблему безопасности (например, возможность повышения привилегий, инъекцию команд через хуки или выход за пределы сеанса в IPC), напишите напрямую автору проекта:
* **Telegram:** [@lyoraeth_art](https://t.me/lyoraeth_art)
* **Discord:** `@lyoraeth`
* Либо через приватную форму **Report a vulnerability** во вкладке *Security* этого репозитория на GitHub.

В сообщении укажите шаги для воспроизведения и версию сборки (`polynya help`).

## Модель безопасности Polynya (архитектурная справка)

Чтобы избежать ложных срабатываний при аудите, ниже описаны проектные механизмы изоляции и работы с системой:

1. **Работа без прав администратора.** Основной процесс `polynya.exe` и встроенные модули спроектированы для работы исключительно с правами обычного пользователя.
2. **Изоляция IPC между пользователями.** Именованный канал управления `\\.\pipe\Polynya-<SessionId>` привязан к идентификатору сеанса Windows текущего пользователя. При быстром переключении учетных записей (Fast User Switching) процессы из соседнего пользовательского сеанса не пересекаются с вашим каналом. Размер одного сообщения в канале жестко ограничен 64 КБ.
3. **Зачем запрашивается UAC в `polynya notify-setup`.** Единственное место, где запрашивается повышение привилегий — разовая регистрация неподписанного sparse-пакета `Polynya.Notify` при ручном включении экспериментального модуля системных уведомлений Windows (требование самой ОС Windows 11 для доступа к `UserNotificationListener` без платного сертификата, код ошибки без админа — `0x80073D2B`). Сам процесс модуля после этого запускается от обычного пользователя через `IApplicationActivationManager`.
4. **Правки реестра в модуле `notify`.** Для подавления дублирующих тостов модуль меняет только пользовательский ключ `ShowBanner` в ветке `HKCU\Software\Microsoft\Windows\CurrentVersion\Notifications\Settings\<AUMID>` (без доступа к `HKLM`) и создает страховочную задачу отката в `HKCU\...\RunOnce\PolynyaBanners` на случай аварийного завершения процесса.
