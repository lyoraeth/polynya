**Polynya** は、Windows 11 のタスクバーの空きスペースにそのまま住み着き、タスクバーを「生きた」情報パネルに変える高速ランチャーです。

**Raycast** や **PowerToys Run** のような従来のランチャーは、呼び出したときだけ動きます。ホットキーを押し、用を済ませて閉じる。それ以外の時間は存在しないのと同じです。Polynya でも `Alt+Space` でプログラムの起動、ファイル検索、計算、ツールの呼び出しができますが、それに加えて画面上に常設の場所を持っています。そのため、余計な操作なしに情報が自然と目に入ります。時刻と天気、リアルタイムのイコライザー付きプレーヤー、バックグラウンドのコマンドやモジュールからの通知が常に見えていて、周りのアイコンやトレイはいつもどおりクリックできます。

さまざまなウィジェットや **Windows 向け Dynamic Island の移植版**とは異なり、画面の上に浮かぶ、場違いなスタイルの独立したウィンドウではありません。Polynya はシステムそのものに溶け込みます。タスクバーの色、縁、輪郭線、粒状の質感をその場で取り込み、テーマ、アクセント カラー、壁紙の変化に追従し、ドロップダウンはタスクバーから滑らかに流れ出してシステムの Mica 素材へとつながります。

ネイティブの **Rust** で書かれ、独自の軽量レンダラーを備えています。ブラウザー エンジン（Electron / WebView）も重い UI フレームワークも使っていません。待機中は **CPU 0%**、メモリは約 **30 MB**。全画面のゲームや動画の間は完全にスリープします。

## 主な機能

* **検索ランチャー（`Alt+Space` または虫眼鏡をクリック）。** プログラムと内蔵機能（カラーピッカー、設定、モジュールのコマンド）の入り口です。デスクトップ アプリとストア アプリのあいまい検索、**Everything** による即時ファイル検索、電卓（三角関数、`0.1 + 0.2 == 0.3` のような許容誤差付きの比較、文字列演算）、通貨換算（`100 usd to eur`、`100$`）。IME とマウスでの選択に完全対応した独自の入力欄、結果の中で直接開ける右クリックのアクション メニューを備え、モジュールの機能は「モジュール › 機能」のように細い列のホットキー付きで表示され、幅で切れた行はツールチップで全文を読めます。

* **プレーヤーとビジュアライザー。** あらゆる Windows メディア セッション（Spotify、YouTube を再生中のブラウザー、デスクトップ プレーヤー）に対応します。5 バンドのスペクトラムは WASAPI process loopback により*プレーヤー プロセス自身の*音声だけを聴くため、Telegram の通知音やバックグラウンドで動いているゲームの音には反応しません。

* **時刻と天気。** 数字がスクロールして切り替わる時計、ホバーで日の出と日の入り、Open-Meteo による 1 時間ごとの予報と 3 日間の予報（API キー不要）。都市は Windows の位置情報から決まるほか、設定で手動入力でき、すぐに反映されます。

* **独立した通知・イベント スタック。** シリーズの統合と「+N」への折りたたみに対応した共有キューで、モジュールやバックグラウンド プロセスからのイベントをタスクバーに直接表示します。
  * **ターミナルの長時間コマンド：** 別のウィンドウにいる間に、Windows Terminal / VS Code でのバックグラウンド ビルドやコマンドが終わると通知します（例：`cargo build · 48 秒`）。

  * **スクリプトやモジュールからの独自のプッシュ：** コンソールからの `polynya push` コマンド 1 つで、または任意の外部モジュールから JSON パイプ経由で送れます。

* **アクセシビリティ。** すべてのコントロールに名前があります。ナレーター、NVDA、JAWS は UI Automation を通じてアイランド、検索結果、モジュールの画面を読み上げ、新しい通知も読み上げます。アイコンだけのボタンや幅で切れたテキストにはツールチップが出ます。

* **全画面時は静かに。** ゲーム、動画、プレゼンテーションの間はタスクバー内のすべてが隠れてスリープし、フレームの描画も音声解析も行いません。

## モジュール

ランチャー、時刻と天気、プレーヤー、通知スタック以外はすべてモジュールです。独立したプロセスで、画面の描画、ホットキー、選択中のテキストはアイランドが受け持ちます。いくつかのモジュールが Polynya に同梱されており、自作のモジュールも同じ方法で書けます。

モジュールは、`module.toml` マニフェストを置いた `%LOCALAPPDATA%\Polynya\modules\<id>\` のフォルダーです。
* **レイアウト作業は不要：** モジュールはデータ（セッションの名前付きパイプまたは `stdin/stdout` 経由の JSON）を渡すだけで、チップ、リスト、トグル、入力欄、アニメーションはアイランドがタスクバーと統一されたスタイルで描画します。
* **どんな技術スタック、どんなライセンスでも：** Rust、Python、Go、C#、JS など何でも使えます。プロトコル仕様と `proto` クレートは **MIT** ライセンスなので、自作モジュールはクローズドや商用を含め、どんなライセンスでも公開できます。
* **1 つのモジュールに 1 つの画面：** `[main]` はモジュールを検索に追加し、`[[functions]]` はそのメニューの項目を同じ名前で検索とグローバル ホットキーに出します（例：`Ctrl+Alt+T` の「翻訳 › 選択範囲を翻訳」）。ホットキーで実行された機能は、アクティブなアプリで選択中のテキストを受け取れます。
* **スクリプトはそのまま：** `main.js`、`main.py`、`main.ps1` はインストール済みの Node.js、Python、PowerShell でビルドなしに実行され、エラーはチップとログに表示されます。

プロトコル、マニフェスト、画面の行タイプの詳細は **[モジュール API](docs/ja/module-api.md)** にあります。Node.js と Python で書いた完成したモジュールは **[サンプル](docs/ja/module-examples.md)** にあります。

### 同梱モジュール

* **AI エージェント（Claude Code、Codex、Cursor）。** エージェントが思考中か、ファイルを編集中か、入力待ちか、タスクを終えたかを表示します。モジュールを有効にするとフックが自動で登録され、設定ファイルを手で触る必要はありません。
* **カラーピッカー。** ランチャーから、画面を止めずに動くルーペを呼び出せます。16 進数の色をコピーし、その色を **OKLCH** の 11 段階のシェードに展開します（Tailwind のスケールと同じ考え方）。
* **Windows 通知（試験的、既定では無効）。** 標準のトースト通知を、タスクバーから出るコンパクトなドロップダウンに置き換えます（UAC による一度きりのパッケージ インストールと、レジストリの `ShowBanner` の変更が必要です。Windows には他のアプリのバナーをオフにする公式 API がないためです）。

* **開発中：独自のスタート メニュー、開発ツール、クリップボード履歴。** まだ同梱されておらず、今後のリリースで追加されます。独自のスタート メニューは `Win` キーの単独押しで、システム操作と「バージョン情報」画面を備えたクイック メニューを開きます。標準ショートカットはいつもどおり使えます。開発ツールは選択した値をホットキーで変換します：`16px` から `1rem`、HEX/RGB/HSL/OKLCH の色、可変 `clamp()`、Unix 時刻、JSON、JWT、Base64、名前の書式。クリップボード履歴はコピーした内容を保存し、アイランドから貼り付け直せます。

## 他のツールとの比較

Raycast や PowerToys のようなランチャーは「必要なときにホットキーで呼び出す」方式です。Polynya はランチャーとしての役割を果たしつつ、最初から画面上にあり Windows の一部のように見える常設の情報パネルも提供します。

| 機能 | Polynya | Raycast for Windows | PowerToys Run / Command Palette |
| :--- | :--- | :--- | :--- |
| **概要** | ランチャー + 生きたタスクバー（常に画面上） | ホットキー ランチャー | ホットキー ランチャー（CmdPal は Run の後継） |
| **呼び出さなくても見える** | **はい：** 時刻、天気、プレーヤー、通知、エージェント | いいえ | いいえ |
| **見た目** | タスクバーの色・縁・粒状感を取り込み + Mica へ移行 | Raycast スタイルの独自ウィンドウ | WinUI スタイルのウィンドウ |
| **技術スタック** | ネイティブ Rust、独自の Direct2D / DComp レンダラー | ネイティブ Raycast クライアント | .NET / WinUI |
| **待機時のリソース** | **CPU 0%、RAM 約 30 MB** | *未計測* | *未計測* |
| **アプリとファイルの検索** | はい（ファイルは Everything 経由） | はい（独自検索） | はい |
| **電卓と通貨** | はい（関数、比較、文字列、為替レート） | はい | はい（通貨はプラグイン経由） |
| **プレーヤーとビジュアライザー** | **はい**（プレーヤー プロセスの音声だけを聴く） | いいえ | いいえ |
| **通知スタックと CLI（`push`）** | **はい**（Windows、ターミナル、自作スクリプト） | いいえ | いいえ |
| **AI エージェントの状態** | **はい**（Claude Code、Codex、Cursor、設定不要） | いいえ | いいえ |
| **OKLCH カラーピッカー** | **はい** | いいえ | いいえ（ピッカーはスイート内の別ツール） |
| **クリップボード履歴、スニペット、ウィンドウ管理** | いいえ | **はい** | いいえ（PowerToys の別ツール） |
| **AI チャット** | いいえ | **はい**（有料） | いいえ |
| **モジュール（拡張機能）** | 任意の言語（パイプ / stdio で JSON、スクリプトはそのまま実行）、描画はアイランドが担当。モジュールの機能にグローバル ホットキーと選択範囲 | JS/TS のストア（一部は macOS のみ） | C# / .NET 拡張機能 |
| **価格とソース コード** | **無料、オープンソース**（GPLv3 / MIT） | 無料、Pro は月額 $8 から、クローズドソース | **無料、オープンソース**（MIT） |

> *注：競合製品の機能と価格は 2026 年半ば時点の情報であり、変わる可能性があります。正確な条件は各公式サイトでご確認ください。*

## パフォーマンス

検証環境：Intel Core i5-10300H（4 コア / 8 スレッド）、内蔵 Intel UHD Graphics、1920x1080、Windows 11（26100）。待機中のメイン スレッドは `GetMessage` で眠っているだけで、長い曲名のスクロールは DWM がコンポジション アニメーションで処理します。

| シナリオ | 平均 CPU | ピーク（1 秒間） | メモリ（アクティブ ワーキング セット） |
| :--- | :--- | :--- | :--- |
| **待機中（時計、天気、チップを表示）** | **0.00%** | - | **26 MB**（コア）/ **約 30 MB**（全モジュール込み） |
| **音楽を再生中（ビジュアライザー動作中）** | **0.52%** | - | 約 30 MB |
| **検索を開いている（キャレット点滅中）** | **0.16%** | 0.58% | 約 35 MB |
| **すべての種類のドロップダウンを開いた後** | **0.00%**（待機時） | 1.34 - 1.72%（アニメーション中） | **約 39 MB**（コア + 常駐モジュールすべて） |

## インストールと起動

**動作要件：** **Windows 11** のみ（x64 または ARM64）。Windows 10 は意図的に非対応です。このツールの核心は新しいタスクバーと Mica 素材に依存しているためです。

1. **[Releases](https://github.com/lyoraeth/polynya/releases)** から、お使いのアーキテクチャ（`x64` または `arm64`）用の最新ビルドをダウンロードします。
   * **インストーラー（`Polynya-<バージョン>-<arch>-setup.exe`）**：基本の選択肢です。管理者権限なしで現在のユーザーにインストールし、モジュールを選べます。Everything がまだなければ、ファイル検索用に一緒にインストールできます。あとで新しいバージョンのインストーラーを実行すると、設定を残したまま上書き更新されます。
   * **ポータブル版（`…-portable.zip`）**：好きな場所に展開して `polynya.exe` を起動します。設定とログは同じフォルダーに保存されます。モジュールは別の `…-modules.zip` に入っているので、同じフォルダーに展開してください。Everything は含まれません。
2. アイランドが自動的にタスクバーに組み込まれ、トレイに設定用のアイコンが表示されます。

アンインストールは **設定 → アプリ → インストールされているアプリ** から行います。Polynya は自動起動、AI エージェントのフック、通知パッケージを取り除き、設定とログも削除するかを確認します。

> **「Windows によって PC が保護されました」：** ビルドにはまだコード署名がないため、新しいバージョンの初回起動を SmartScreen が止めることがあります。**詳細情報 → 実行** をクリックしてください。

> **管理者権限について：** Polynya は**管理者権限なしの通常ユーザーとして**起動してください。アイランドに昇格は不要で、むしろ害になります。Windows の特権分離（UIPI）により、管理者として動くプロセスは Everything の検索と正常に通信できません。UAC が求められるのは、Everything のインストールと、試験的な Windows システム通知の取り込みモジュールを有効にするときだけです。

## コマンドライン（CLI）

ターミナルや自作のスクリプトから、スタックに通知を送ったりアイランドを操作したりできます。

```powershell
# タスクバーにチップを表示（既定で 10 秒表示）
polynya push "deploy done" "prod · 42 s" --icon ok --key deploy

# 同じキーでチップを更新（キューを待たずに先頭へ）
polynya push "tests failed" "error in auth" --icon fail --key deploy

# キーを指定して通知を消す
polynya dismiss deploy

# タスクバーの色を取り込み直す（Windhawk などのパッチの後に便利）
polynya refresh

# モジュールのコードを変更した後にモジュールのプロセスを再起動
polynya modules reload
```

## 開発の方法

このプロジェクトの開発には生成 AI を使用しています。
Polynya は [agentic engineering](https://simonwillison.net/2026/may/6/vibe-coding-and-agentic-engineering) の手法で作られています。
コードとドキュメントは [Claude Code](https://claude.com/claude-code)（Anthropic）と一緒に書いています。
アイデア、プロダクトとインターフェースの判断、アーキテクチャの選択、ビジュアルデザインは私が担当し、
実装は私の指示のもとで Claude が書いています。こうした判断をこの種のプロダクトに必要なレベルで行うために、
Rust のドキュメント、Windows の開発者フォーラム、同じジャンルの他プロジェクトのソースコードを自分で読み込み、
Claude の実装が検証に耐えなかった部分は手で書き直しました。

すべての変更は、プロジェクトに入る前に実際の Windows 11 タスクバーで動作を確認しています。
さらにリリースのたびに、ローカルでテストを行い境界ケースを確認しています。
想定外の動作に遭遇した場合は、[issues](https://github.com/lyoraeth/polynya/issues) または個別のメッセージ（連絡先は上記）で内容をお知らせのうえ、
ログ（`%LOCALAPPDATA%\Polynya\logs\polynya.log`）を添付してください。

私はすべてを知っているわけではありませんが、より良くなろうと努め、学ぶことを楽しんでいます。
アーキテクチャや構文の誤り、コード内の潜在的に危険な箇所を見つけたら、[issues](https://github.com/lyoraeth/polynya/issues) または
[ディスカッション](https://github.com/lyoraeth/polynya/discussions) に、どこが問題か、なぜ良くないか、どうすればより良くなるかを書いていただけると、とてもありがたいです。
